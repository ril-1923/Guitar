# STRINGS — Interactive Guitar Experience

A premium, highly interactive guitar showcase website built with **HTML5**, **CSS3**, **JavaScript ES6+**, **Bootstrap 5**, and **Bootstrap Icons**.

## Features

- **Cinematic Hero** — Animated gradient background, floating guitar, glowing particles, musical notes
- **Guitar Collection** — 6 guitar cards with category filtering (All / Acoustic / Electric / Bass / Classic)
- **Moving Guitar Experience** — Guitar moves, rotates, and scales on scroll
- **Color Customizer** — 6 guitar finishes with live image swap and glow effects
- **Play the Strings** — 6 interactive guitar strings with Web Audio API tones
- **Features Section** — 6 craft feature cards with hover animations
- **Animated Stats** — Counters that animate when scrolled into view (IntersectionObserver)
- **Gallery** — 8-image responsive grid with Bootstrap modal lightbox
- **Testimonials** — Bootstrap carousel with 4 reviews
- **Timeline** — Animated guitar journey from 1950 to 2026
- **5 Color Themes** — Midnight, Sunset, Ocean, Forest, Vintage (saved in localStorage)
- **Multiple Google Fonts** — Bebas Neue, Montserrat, Inter, Cinzel, Playfair Display, Space Grotesk
- **Scroll Reveal Animations** — 14 reusable CSS keyframe animations triggered by IntersectionObserver
- **Responsive Design** — Optimized for desktop, tablet, and mobile
- **Accessibility** — Semantic HTML, keyboard navigation, focus states, prefers-reduced-motion support
